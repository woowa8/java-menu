# 미션 - 점심 메뉴 추천 구현 기능 정리
## View
### InputView
- [ ] 코치 이름 입력 받는 부분
- [ ] 코치별로 못 먹는 음식 입력 받는 부분
- 예외 처리
    - [ ] 코치 이름에 빈칸이 들어올 경우

### OutputView
- [ ] 서비스 문구 인트로 출력
- [ ] 메뉴 추천 결과 출력
- [ ] 추천 완료 메세지 출력

---

## Domain
### User
- 기능 구현
    - [ ] 이름, 못 먹는 음식 (MenuList)을 가짐
    - [ ] getter
- 예외 처리
    - [ ] 코치 이름이 2글자 미만일 경우
    - [ ] 코치 이름이 4글자 초과일 경우

### Category (ENUM)
- 기능 구현
    - [ ] 순서대로 1이면 일식, 2면 한식, 3이면 중식, 4면 아시안, 5면 양식
    - [ ] getter

### Menu
- 기능 구현
  - [ ] 메뉴 이름
  - [ ] 카테고리 종류
  - [ ] getter
  - [ ] add 하는 기능
---

## DTO
### ResponseDto
- 출력을 위한 정보를 가지고 있는 dto
- 기능 구현
  - [ ] user 리스트, 카테고리 리스트, 유저가 먹는 음식을 순서대로 담는다.

## Util
### InputParser
- 기능 구현
    - [ ] , 로 구분
    - [ ] 구분한 결과를 List<String>으로 반환
- 예외 처리
    - [ ] 같은 이름이 중복이면 에러
    - [ ] 코치가 2명 보다 작으면 에러
    - [ ] 코치의 수가 5명 보다 크면 에러

### InitData
- 기능 구현
    - [ ] 초기 메뉴로 주어진 것을 repo에 저장

---
## Repository

### MenuRepository
- [ ] 메뉴 목록을 저장한다.
- [ ] 메뉴 이름으로 찾는 기능이 존재한다.

### UserRepository
- [ ] 유저들을 저장한다.
- [ ] 유저 이름으로 찾는 기능이 존재한다.

## Service
### MenuService
- 기능 구현
    - [ ] 랜덤 카테고리 고르기
    - [ ] 랜덤 메뉴 고르기
    - [ ] 요일별 메뉴 골라서 저장하기
    - [ ] 출력하기
- 예외 처리
    - [ ] 이미 있는 메뉴는 중복할 수 없음(한 사람당)
